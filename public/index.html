DOCUMENTATION

Simulation guide

Explore the physical model, experiment parameters and numerical diagnostics used by ORBITAL.

01 QUICK START

Getting started

Configure the primary and secondary bodies, choose the initial orbital conditions and set the simulation duration.

02 PHYSICS

Physical model

Model gravitational interactions using Newtonian mechanics and a numerical integration method designed for orbital dynamics.

03 CONFIGURATION

Parameters & units

Mass, distance, velocity and duration can be configured using the units available in the experiment panel.

04 GEOMETRY

Trajectory

Inspect the motion of both bodies in the XY plane. The analysis view expresses positions in astronomical units.

05 TIME SERIES

Physical state

Track distance, velocity, total energy and angular momentum throughout the integration interval.

06 VALIDATION

Numerical metrics

Use relative errors, computation time and integration step count to evaluate a simulation's numerical behavior.

i
INTERPRETATION NOTE

Numerical results depend on the initial conditions, integration step and duration. Small conservation errors are useful diagnostics, but should always be interpreted in context.
